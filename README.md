# PowerBI-HR-Analytics-Dashboard
Interactive Power BI dashboard analyzing workforce data including salary trends,  performance metrics, and employee attrition patterns
**Tools Used:** Power BI | DAX | Power Query | Excel

**Dataset:** 300 employee records (anonymized)
**Dataset:** 250 Active employee records anlaysis
---

## Key Features

### 1. HR Pulse Dashboard
- Real-time headcount tracking
- Department-wise distribution
- Job Level Distribution
- Hiring Trends
- Employees By Gender

### 2. Compensation Analytics
- **Overtime vs Salary correlation analysis**
- Pay equity across departments
- Performance-based salary distribution

### 3. People Trends
- Attrition rate: 17%(identified high-risk)
- Demographics breakdown
- Retention strategy recommendations

---

## Technical Details

### Data Modeling
- Star schema with 4 dimension tables
- one Calendar Table For Time Series Analysis
### DAX 
- 15+ DAX measures including time intelligence
